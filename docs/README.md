# SkyOPHQ Documentation

This directory contains the canonical architecture and implementation documentation for the SkyOPHQ ecosystem.

- [SkyOPHQ Architecture](./SKYOPHQ-ARCHITECTURE.md) — source-of-truth architecture for the public portfolio, private documentation layer, active Investor Operations project, independent AI Tutor Pro project, and archive policy.

## Working rule

Before changing application architecture or creating a new SkyOPHQ project, check the architecture document first. The goal is to prevent disconnected versions of the company structure from accumulating across projects.
